# Mixx Trace name and logo

These files are the Mixx Trace logo: an MT monogram of three upright posts and one red line. The
line is the measurement trace. It dips like an EQ cut to form the M, then runs flat as the
crossbar of the T.

| File | Use |
| --- | --- |
| `mixxtrace-logo-on-light.svg` | mark and name, black and red, for white or light backgrounds |
| `mixxtrace-logo-on-dark.svg` | mark and name, white and red, for black or dark backgrounds |
| `mixxtrace-logo-stacked-on-light.svg`, `mixxtrace-logo-stacked-on-dark.svg` | mark above the name |
| `mixxtrace-mark-on-light.svg`, `mixxtrace-mark-on-dark.svg` | monogram only |
| `mixxtrace-mark-one-colour.svg` | single colour, takes the surrounding text colour |
| `mixxtrace-app-icon.svg` | app icon (the Mac icon is drawn by `packaging/mac/make_icon.py`) |
| `social-preview.png` | 1280 x 640 image for the repository's social preview |

Colours: red `#E3101C`, black `#0A0A0A`, white `#FFFFFF`. The name is set in Switzer Semibold
(Indian Type Foundry, ITF Free Font License) and converted to shapes, so no font is needed.
