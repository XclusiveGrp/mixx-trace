    Hooking up a DiGiCo Quantum 326

    1. USB. Connect the console's UB MADI port (USB Type B) to the computer. It carries up to 48 channels each way. On macOS Catalina or later no driver is needed; on Windows install DiGiCo's UB MADI driver and pick the ASIO device here.
    2. Reference. Route a copy of what feeds the PA (the master or matrix output you are tuning) to a UB MADI output socket. Select that channel as Reference.
    3. Measurement mic. Plug the measurement mic into a console preamp and route that input, pre-processing, to another UB MADI output socket. Keep it out of the mix. Select it as Measurement mic.
    4. Channels to scan. Send the inputs you want advice on to the remaining UB MADI sockets (record sends work well). Name them on the Channels tab.
    5. Apply. System EQ goes on the output or matrix EQ (8 bands). Channel fixes go on the input strip: HPF, four EQ bands that can each run dynamic, and the dynamics section.

    Any other interface works the same way: it only needs one input for the mic and one for the reference.

    TuneTrace Levels are dBFS at the interface, not SPL.
